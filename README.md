# Rădăcina cifrelor

Un script mic în Python care adună cifrele unui număr până rămâne o singură cifră și îți spune dacă iese 3, 6 sau 9.

```
python3 radacina.py 1728
1728: 1728 -> 18 -> 9
Rădăcina e 9: număr 3-6-9.
```

Fără argumente folosește ora curentă. Nu are dependențe și nu se conectează la internet.
